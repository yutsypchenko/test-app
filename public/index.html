Симулятор розподіленої системи

Моделюйте потік запитів до API / бази даних і спостерігайте, як співвідношення між інтенсивністю навантаження та обчислювальною здатністю системи впливає на довжину черги, час очікування та кількість оброблених запитів.

Гіпотеза

«Коли частота надходження запитів перевищує здатність API/БД обробляти їх, довжина черги зростає, а час очікування збільшується».

Очікуваний результат

Прогноз за гіпотезою — до запуску симуляції.

Стабільна робота ρ = 1.00

  • Навантаження нижче пропускної здатності — черга не накопичується або швидко зникає.
  • Навантаження ≈ пропускній здатності — система працює на межі своїх можливостей.
  • Навантаження перевищує пропускну здатність — черга зростає, час очікування збільшується.

Обмеження моделі

Симуляція є спрощеною детермінованою моделлю реальної розподіленої системи.

  • Час обробки запитів вважається фіксованим.
  • Не моделюються помилки API та БД.
  • Не враховується мережна затримка.
  • Не моделюється динамічне масштабування.
  • Виконавці мають однакову продуктивність.
  • Не враховуються блокування, повторні запити та пріоритети.
  • Модель призначена для демонстрації основних принципів роботи черги.
  • Запити надходять рівномірно (без випадкових сплесків).
